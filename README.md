## 🚀 How to View & Run Locally

1. **Direct Browser Launch**:
   - Double click `index.html` in your file explorer to open the portfolio in Google Chrome or Microsoft Edge.
   - Double click `Ankesh_Kumar_Resume.pdf` to view your printable PDF resume.

2. **Run with Python Local Server**:
   Open a terminal in `d:\Portfolio` and run:
   ```bash
   python -m http.server 3000
   ```
   Then open `http://localhost:3000` in your browser.

## 🌐 Free One-Click Deployment to the Web

You can easily host this portfolio for free with your own URL:
- **GitHub Pages**: Create a repo named `portfolio` on GitHub, push these files, and turn on GitHub Pages in repository settings.
- **Netlify / Vercel**: Drag and drop the `d:\Portfolio` folder into [Netlify Drop](https://app.netlify.com/drop) or [Vercel](https://vercel.com) for instant live HTTPS deployment.
